# AI Interview Coach 🤖

A GenAI-powered mock interview platform that generates multi-round, difficulty-adaptive interview questions and evaluates answers using Gemini LLM.

## Features
- 3-round interview simulation  
- Easy / Medium / Hard difficulty  
- Role-based questions  
- AI evaluation with score & model answers  
- Flask web interface  
- Prompt engineering pipeline

## Tech Stack
- Flask  
- Google Gemini  
- Python  
- Bootstrap

## How to Run

1. Clone
git clone https://github.com/yourusername/ai-interview-coach.git

cd ai-interview-coach

2. Install
pip install -r requirements.txt


3. Create `.env`
OPENAI_API_KEY=your_key


4. Run
python app.py
